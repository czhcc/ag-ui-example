## 验证入口

Java 21、Maven 3.9+：在根目录运行 `mvn test`。Schema 测试使用 test-scope networknt 1.5.7 验证 Draft 2020-12，逐条读取 `mcp-contract/src/test/resources/schema/manifest.json`，包括合法、非法、旧版本兼容与 Profile fixture。

前端测试要求 Node 22.13+（支持 `--experimental-transform-types`），在根目录执行 `pnpm --filter @ac/agent-ui test`。单元测试不启动服务；真实服务测试在未设置 `AC_LIVE_E2E=1` 时跳过。

端到端测试前，启动 MCP Server、配置可调用工具的模型，并启动两个 Runtime。PowerShell 示例：

```powershell
$env:AC_LIVE_E2E = '1'
$env:AC_SAA_URL = 'http://localhost:8080'
$env:AC_AGENTSCOPE_URL = 'http://localhost:8082'
pnpm --filter @ac/agent-ui test
```

真实测试可能产生模型调用费用，要求模型完成 `kg_activity_statistics` 和 `ui_render`。模型未调用工具、后端断开或鉴权失败都会使测试失败，不自动忽略。`AC_E2E_PROMPT` 可指定与测试数据匹配的查询。测试使用 SDK HTTP 客户端，不等价于官方 AG-UI Client 互操作认证。

## 发布要求

保留 Java、Node 版本、测试报告、端到端模型/工具配置（不含密钥）、通过/失败/跳过数量与 Git revision。真实服务用例跳过时不能声称端到端验收通过。共享存储标记接口不能替代 Redis 持久化、原子配额、故障恢复和跨副本事件投递验证。

端口、模型配置与最小请求参见 [双 Runtime 接入](双Runtime最小接入.md)，安全边界参见 [安全与存储策略](安全与存储策略.md)。
